# Setting XPrinter as Default Printer in Windows

## Steps to Set Default Printer

1. **Connect Your XPrinter**
   - Connect the XPrinter to your computer via USB cable
   - Or ensure it's connected to the same network if using network/WiFi connection
   - Wait for Windows to recognize and install the printer drivers

2. **Open Windows Settings**
   - Press `Windows Key + I` to open Settings
   - Or click Start Menu \u003e Settings (gear icon)

3. **Navigate to Printers**
   - Click on **Devices**
   - Select **Printers & Scanners** from the left menu

4. **Set as Default**
   - Find your XPrinter in the list of printers
   - Click on the printer name
   - Click **Manage** button
   - Click **Set as default** button
   - ✅ Your XPrinter is now the default printer!

## Alternative Method (Control Panel)

1. Press `Windows Key + R`
2. Type `control printers` and press Enter
3. Right-click on your XPrinter
4. Select **Set as default printer**

## Verification

- The default printer will have a green checkmark (✓) icon
- Windows will now automatically use this printer for all print jobs
- The POS system will automatically send receipts to this printer

## Troubleshooting

If XPrinter doesn't appear in the list:
1. Check USB cable connection
2. Try a different USB port
3. Restart the printer
4. Install XPrinter drivers from the manufacturer's CD or website
5. Restart your computer

## POS Receipt Printing

After setting XPrinter as default:
1. Complete a sale in the POS system
2. Receipt preview modal will appear
3. Click "Print Receipt" button
4. Receipt will automatically print to XPrinter
5. No need to select printer each time!

---

**Note**: If you have multiple printers, Windows will remember XPrinter as default until you change it.
